# 💱 Currency Converter

A simple Currency Converter built with React and Tailwind CSS.

## Features

- Convert currencies in real time
- Select currencies using dropdown menus
- Dynamic country flags
- Uses Currency API for live exchange rates
- Responsive and clean UI

## Tech Stack

- React.js
- Tailwind CSS
- JavaScript
- Currency API

## API Used

https://cdn.jsdelivr.net/npm/@fawazahmed0/currency-api

## Installation

```bash
git clone https://github.com/codeby-shubham/Currency-Converter-.git
cd Currency-Converter-
npm install
npm run dev
```
